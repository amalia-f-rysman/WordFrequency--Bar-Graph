# WordFrequency--Bar-Graph
- Word counts visualized through bar graph using OOP and Arrays in Processing (Java)
- Practice Project

## Focusing on:
- Using Objects in a OOP program
- Managing data within an ArrayList
- String manipulation
- Searching collections efficiently

## Overview
- Reads text from a file
- Removes any extra spaces or punctuation
- Counts and stores the frequency of each word appearing
- Displays results in readable bar graph
